# Recto

Fiches de révision dans le navigateur : créez vos listes de cartes (terme et définition), puis révisez-les avec cinq modes.

- **Cartes** : retournez les cartes et triez-les entre « Je sais » et « À revoir »
- **Apprendre** : choix multiple puis réponse écrite, par groupes de sept cartes
- **Écrire** : tapez la réponse, les accents oubliés sont tolérés
- **Test** : choix multiple, vrai ou faux et réponses écrites, avec la correction
- **Associer** : reliez chaque terme à sa définition contre la montre

On peut ranger les listes dans des dossiers et importer une liste collée depuis un tableur ou un document (tabulation, tiret, virgule ou deux-points entre le terme et la définition).

Les listes et la progression sont enregistrées dans le navigateur de chacun (localStorage) : rien n'est envoyé sur un serveur.
